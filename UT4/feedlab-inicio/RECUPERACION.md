# Puntos de recuperación por sesión

Conserva siempre una copia de tu trabajo antes de empezar la siguiente sesión. Estos puntos permiten practicar la idea nueva con los datos de `datos-practica.json` aunque una integración anterior esté pendiente. No incluyen soluciones de las actividades.

| Antes de la sesión | Punto de partida mínimo | Si todavía no lo tienes |
| --- | --- | --- |
| 1 | HTML/CSS del ZIP | Abre `index.html` con `npx serve .` |
| 2 | Array de publicaciones | Importa `datos-practica.json` o copia sus objetos a un módulo |
| 3 | Función que recibe una callback | Usa `lista.filter(criterio)` como ejemplo de clase |
| 4 | Array de posts | Usa `datos-practica.json` y empieza por `filter` |
| 5 | Lista filtrada | Usa la lista completa del JSON y compara dos órdenes |
| 6 | Array de posts con likes | Usa el JSON y empieza por el total |
| 7 | Lista y objeto originales | Copia el JSON antes de cada prueba de mutación |
| 8 | Forma real del post | Consulta el modelo `Post` en Swagger o el JSON local |
| 9 | API y proyecto arrancados | Comprueba `/health`; si responde 503, avisa al profesor |
| 10 | Función pura de puntuación | Usa la fórmula del comentario de `recomendaciones.js` y el JSON |
| 11 | Funciones de las sesiones previas | Crea módulos con las funciones que sí hayas terminado |
| 12 | Al menos un filtro y un orden | Usa los datos locales para depurar y escribir regresiones |

Cuando recuperes una función pendiente, sustitúyela en tu proyecto principal y vuelve a probar el recorrido completo. El profesor puede entregar la solución de la sesión anterior cuando corresponda; este archivo no adelanta la siguiente.
